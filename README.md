# pj55-harees-website-2026

## Harees Jewellery SaaS Platform & E-Commerce Application

A full-stack e-commerce and gold savings scheme application built with Angular 18 (Frontend) and Django REST Framework (Backend) with PostgreSQL database integration and PhonePe payment gateway capabilities.

### Key Features
* **Modern Mobile-First E-Commerce Layout**: 2-column product grids, search and filter controls, and interactive bottom navigation bar.
* **Gold Savings Scheme System**: Installment planning, weight index calculations, and advance gold booking.
* **PhonePe Gateway Integration**: Base64 payload generation, SHA256 checksum verification (`X-VERIFY`), and payment status polling.
* **Interactive OpenAPI Swagger Documentation**: Accessible at `/api/docs/`.
